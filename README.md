# Signature Generator

A modern signature generator and drawing application built using HTML, CSS, JavaScript, and Spring Boot.

## Features

- Generate stylish handwritten signatures
- Regenerate signatures with different styles
- Draw signatures using mouse or touch
- Download transparent PNG signatures
- Responsive mobile-friendly UI
- Smooth animations and modern design

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Java
- Spring Boot
